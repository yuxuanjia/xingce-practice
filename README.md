# 行测刷题台

一个纯原生 HTML / CSS / JavaScript 的本地刷题前端。它读取同级题库目录中的 Markdown 试卷，所有做题数据只保存在浏览器本地。

## 功能

- 按模块、省份 / 来源、试卷随机出题
- 单选、多选自动判分与官方解析
- 每题实时计时、累计用时和正确率
- 错题本：自动收录错题，点击即可重做；答对后自动移出
- 键盘快捷键：`A`–`D` 选项、`Enter` 提交、`N` 换题
- 正确识别资料分析的材料与图片

## 使用

将本目录放入题库根目录。题库根目录需要具有下列结构：

```text
题库根目录/
├── 01-政治理论/
├── 02-常识判断/
├── …
├── 90-图片/
└── 刷题网页/
```

在 `刷题网页` 目录运行：

```bash
node build-index.mjs
node server.mjs
```

访问 <http://127.0.0.1:4173> 即可开始。题库增删或更新后，再运行一次 `node build-index.mjs`。
